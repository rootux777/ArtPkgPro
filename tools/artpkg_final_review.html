What this workflow sends forward

      
The reviewed package and source evidence are sealed together. Preparation creates a separate project workspace, preserves the sealed files, adds working instructions and suggested prompts, and opens a blank session using DSH’s standard coding preset.

      
A prior seal is never overwritten. Adding final review to an older package creates a reviewed revision. Downloading the old seal or using the optional advisory reviewer does not complete this workflow.

      
The receipt stays plan-only with implementation authority NONE. Approve the bounded build scope and permissions separately in DSH. Select plan mode and workspace-write with human approvals before sending a prompt.
